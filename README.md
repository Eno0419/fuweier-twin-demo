# 富威尔数字孪生 DEMO

**展示 DEMO：仅展示业务逻辑，不代表真实原型和最终画面。**

React 19 + Three.js / React Three Fiber + Drei + Zustand + React Flow + ECharts，Vite 静态应用。

## 启动

```powershell
npm install
npm run dev -- --port 5173
```

浏览器打开 http://127.0.0.1:5173/ 。正式静态构建运行 `npm run build`，产物在 `dist/`；可运行 `npm run preview` 验证产物。

## GitHub Pages 部署

仓库：`Eno0419/fuweier-twin-demo`。在仓库 Settings → Pages 中选择 GitHub Actions 作为发布来源。

`.github/workflows/pages.yml` 在 `main` 分支更新时自动执行 Node.js 24 安装依赖、11 项测试、生产构建及 Pages 发布。也可在 Actions 手动运行。发布地址以 Pages 设置页和成功部署结果为准。

Vite 与 GLB 使用相对路径，同一产物可部署到域名根路径或 `/fuweier-twin-demo/` 子目录。使用 `npm run preview -- --base /fuweier-twin-demo/` 可验证子目录部署。浏览器内的配置和事件记录按站点域名存储，不会从旧网址自动迁移。

1. 总览 → 查看楼层结构 → 楼层展开 → L3 → 梁柱墙体显隐 → 全厂视角。
2. 异常工作台 → 纺丝箱体温度高限 → L3 设备定位 → 同期趋势 → 关联视频和人员 → 处置备注 → 确认 → 恢复 → 关闭。
3. 业务追溯 → 输入 PK-20261025-0086 → 查看批次和桶次 → 点击关联设备 → 历史时段；第二条包记录展示关联断点。
4. 安防监控 → 搜索 CAM-01 → 视频 → 关联设备 → 多画面；CAM-05 演示离线。

## 模型与数据边界

原始模型 `public/fuweier-factory-site.glb` 保留不改。6,130,556 字节、1,252 网格、91,444 三角面。只有 P1_TOWER 含 848 个详细建筑结构构件及 7 个楼层标高。所有节点原本平铺，使用其 extras 属性组织显示。其余建筑以外形为主，去顶时隐藏体块与立面，不代表已有真实室内。

模型中的 CAD 草稿、推定位置和未验收状态仍成立。设备及测点身份依据原表，坐标和楼层分配参考新增连续干燥图纸的七个标高及相关注记作示意布置，所有设备位于塔楼边界内，尚未逐台配准。相机覆盖、人员、生产量、批次和异常为演示数据，真实及历史测点读数尚未接入。来源、统计口径、原表疑点与 CAD 参考方式见 `DATA-SOURCES.md`。

模拟视频由浏览器 canvas 动态绘制后经 captureStream 送入 video，明确标识非现场视频。未接入实时监控、录像、真实人员轨迹、定位设施或业务底座。权限选择器只是 UI 演示，不是生产鉴权。示例事件状态变化不自动改写设备测点或设备状态。

楼层展开只改变显示坐标，不改写真实空间锚点；摄像头、设备和人员使用同一个偏移函数。场景与面板共用 Zustand 中的对象、建筑、楼层和时间上下文。历史演示时间为 2026-10-25 14:00–15:00。

## 维护入口

- `src/equipment-source.json`：原表设备和测点字段、来源行号、源文件哈希。
- `src/catalog.ts`：来源记录与塔楼示意楼层、位置和模型类型的映射。
- `src/EquipmentDetails.tsx`：设备详情弹窗与可搜索测点清单。
- `src/data.ts`：原表目录引用、演示业务、人员、摄像头及中文标签。
- `src/model-index.json`：从 GLB 生成的建筑、楼层世界坐标边界。
- `src/store.ts`：专题、空间、对象、时间与角色状态。
- `src/domain.mjs`：楼层偏移、状态迁移、详情选择与有效定位计算。
- `src/Scene.tsx`：模型、构件显隐、相机、三维设备和锚点。
- `src/App.tsx`：七大业务界面、处置记录和点位编辑。
- `scripts/audit-model.mjs`：运行 `npm run audit:model` 可重新生成模型索引。

业务数据正式接入时，替换 `data.ts` 的数据提供层，通过统一业务服务保存处置记录；为模型、设备、产线、参数、摄像头和定位数据设置稳定 ID。视频接入需要浏览器兼容的授权播放服务。定位人员的权限与有效期由服务端验证。
